# Roadmap de Certificaciones Técnicas

Dashboard interactivo para seguir certificaciones de Data, BI, Nube y SAP: estado, personas que las cursan, fechas objetivo, bitácora, costos en USD/CLP y enlaces oficiales.

Los datos se guardan en el navegador de cada visitante (localStorage). Usa **Exportar / Importar** para respaldar o compartir el progreso.
